# Dubas

Двуязычный сайт веб-студии на Next.js и TypeScript. Русская версия открывается на `/`, английская на `/en/`. Страницы собираются в статические HTML, CSS и JS. Для приёма заявок нужен прилагаемый Node.js-сервер или отдельно размещённый совместимый API.

Услуги: интернет-магазин, сайт-визитка, лендинг и многостраничный сайт. Переключатель показывает подходы на основе шаблона и индивидуальной разработки. Кнопка оценки переносит выбранные тип сайта и подход в форму.

## Запуск

Требуется Node.js 24 или новее и npm. В PowerShell:

```powershell
cd D:\OtherProjects\MyPortfolioSite
npm ci
npm run dev
```

Откройте адрес, напечатанный в терминале. Обычно это `http://127.0.0.1:3000`. Команда запускает Next.js и локальный API на порту 3001. Если старая версия `npm run dev` уже запущена, остановите её и запустите заново. Порты можно изменить переменными `PORT` и `INQUIRY_DEV_PORT`.

## Сборка

```powershell
npm run build
npm run typecheck
npm run preview
```

Архив `dubas-app.zip` включает исходники, готовые страницы и сервер приёма заявок. После распаковки можно запустить `npm run preview` с установленным Node.js 24. Для разработки сначала выполните `npm ci`. Каталог заявок создаётся при запуске и в архив не включён.

`npm run build` создаёт папку `out`. `npm run preview` раздаёт её содержимое на `http://127.0.0.1:3000` и принимает POST-запросы на `/api/inquiries`. Next.js runtime при этом не запускается. Порт можно изменить через переменную `PORT` или командой `npm run preview -- --port 4173`.

Для просмотра только статических страниц через Python:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory out
```

Сервер Python не принимает заявки. Для проверки формы используйте `npm run dev` или `npm run preview`.

## Заявки

Форма запрашивает имя, телефон или email, описание проекта и отдельное согласие. Тип сайта и подход можно оставить неопределёнными. Валидация выполняется в браузере и повторяется на сервере. Подтверждение появляется только после успешной записи.

Заявки сохраняются в `.data/inquiries.ndjson`, по одной JSON-записи на строку. Папка находится вне `out`, исключена из Git и не должна попадать в публичные архивы. Поля записи: идентификатор, дата, срок хранения, имя, контакт, описание, тип сайта, подход, язык и версия согласия. IP-адрес в файл заявки не записывается. Счётчики защиты от частых запросов временно используют его в памяти.

Срок хранения составляет до 90 дней. Очистка выполняется при запуске API, при сохранении новой заявки и раз в сутки, пока процесс работает. Для отдельного запуска очистки: `npm run inquiries:prune`. Если сервер не работает, для своевременной очистки нужно запускать эту команду по расписанию на хостинге.

Файл можно открыть локально в редакторе. Доступ к нему через HTTP не предусмотрен. Telegram-бот и email-уведомления пока не подключены. Ограничьте доступ к папке средствами ОС и резервного копирования. Данные не шифруются приложением; не храните их в публичной общей папке.

API принимает JSON по `POST /api/inquiries`. Успех возвращает HTTP 201 и `{ "id": "...", "status": "saved" }`. Ошибки проверки возвращают 422, частые запросы 429, недоступность хранилища 503. Неверный Origin, неподдерживаемый формат тела, слишком большой запрос и заполненное поле-ловушка отклоняются. Лимит составляет 8 попыток с одного адреса за 10 минут.

При отдельном размещении API укажите `NEXT_PUBLIC_INQUIRY_ENDPOINT` перед сборкой страниц. Разрешённые origin-адреса задаются на сервере в `INQUIRY_ALLOWED_ORIGINS` через запятую. `INQUIRY_STORAGE_DIR` задаёт каталог хранения. Настройки запуска Node.js передаются в окружении процесса; `.env.local` автоматически читает Next.js, но не отдельный сервер Node.js. Не помещайте секреты будущего Telegram-бота в переменные с префиксом `NEXT_PUBLIC_`.

Одновременно используйте один процесс приёма заявок на один каталог. Файловое хранилище рассчитано на локальную версию и небольшой одиночный сервер. Для нескольких экземпляров потребуется общая база данных или другой согласованный механизм записи.

## Контент и настройки

- `src/lib/content.ts` содержит тексты обеих локалей, проекты и объект `site` с контактами и сведениями об исполнителе.
- `src/components/Site.module.css` содержит оформление, адаптивные размеры и анимации. Общие стили и локальный шрифт находятся в `src/app/globals.css`.
- `src/lib/seo.ts` содержит метаданные и проверку готовности к индексации.

Чтобы добавить прямой контакт, замените `site.telegram` на полный HTTPS-адрес Telegram и `site.email` на email. Пока значения равны `null`, дополнительные прямые ссылки не показываются. Форма заявки работает независимо от них. Не указывайте вымышленные адреса.

Проекты хранятся в массиве `projects`. Для каждого нужны уникальный `slug`, статус `live` или `concept`, локальное изображение и тексты на двух языках. Страницы кейсов генерируются при сборке.

## Перед публикацией

1. Заполните контакты, имя исполнителя и его реквизиты в `site`. Dubas является рабочим названием бренда. Оно не обозначает зарегистрированное юридическое лицо.
2. Проверьте право на публикацию материалов реального кейса. Роль автора в martamarafon.by указана со слов владельца этого проекта: дизайн, разработка, интеграция оплаты и запуск. Показатели продаж и отзывы не заявлены.
3. Уточните актуальные требования к размещению, регистрации ресурса и сведениям об исполнителе применительно к вашему статусу НПД. Публикация и регистрационные действия не входят в локальную версию.
4. Обновите обе страницы конфиденциальности под фактического оператора, каналы переписки и хостинг. Уточните обработку серверных журналов, сроки хранения, основания обработки и порядок обращения по вопросам данных.
5. Скопируйте `.env.example` в `.env.local`. Укажите реальный домен в `NEXT_PUBLIC_SITE_URL`, например полный HTTPS-адрес без завершающего слеша. Установите `SITE_INDEXABLE=true` только после подготовки сайта к публикации.
6. Выполните сборку заново. Для работы формы разместите страницы вместе с Node.js-сервером за HTTPS-прокси либо подключите отдельный API. Один архив `dubas-static.zip` содержит только страницы и изображения, без сервера и данных заявок. На обычном статическом хостинге без API отправка работать не будет. Сервер должен раздавать `index.html` внутри каталогов и `404.html` с HTTP-статусом 404 для неизвестных адресов.

По умолчанию все страницы содержат `noindex, nofollow`, а `robots.txt` запрещает обход. Индексация останется закрытой, пока не заполнены домен, имя, налоговый номер и хотя бы один контакт, даже если установлен флаг `SITE_INDEXABLE=true`. Sitemap пуст, пока не задан настоящий домен. Настройка индексации не является защитой доступа к опубликованному сайту.

## Данные и внешние запросы

Есть форма оценки проекта с локальным файловым хранилищем. Нет учётных записей, аналитики, cookies и записи в localStorage. Шрифт и изображения локальные. Данные формы отправляются только по явному нажатию кнопки после согласия. Telegram и email-уведомления не подключены. Ссылка на реальный проект открывает martamarafon.by во внешней вкладке.

Уменьшение движения в настройках системы отключает анимации и плавную прокрутку. FAQ работает на стандартных элементах `details` без JavaScript. Мобильное меню поддерживает Escape и перемещение фокуса клавишей Tab.

## GitHub Pages

Репозиторий проекта: https://github.com/DubaOk/dubas
Тестовая версия: https://dubaok.github.io/dubas/

GitHub Pages публикует готовую сборку из корня ветки `gh-pages`. Исходники находятся в `main`. Публикация ветки запускает встроенное развёртывание Pages на стороне GitHub.

```powershell
npm ci
npm run deploy:pages
```

Команда собирает статическую версию с префиксом `/dubas`, добавляет `.nojekyll` и отправляет содержимое `out` в `gh-pages`. Нужна авторизация GitHub CLI через `gh auth login`. Токен используется через менеджер учётных данных CLI. Исходники в `main` отправляйте обычным `git push` после коммита изменений. Команда публикации не меняет рабочую папку и не переписывает историю веток.

Для одной сборки без публикации выполните `npm run build:pages`. Для обычного локального просмотра с приёмом заявок выполните `npm run build`, затем `npm run preview`. Эти сборки используют одну папку `out` и заменяют друг друга.

На Pages форма отключена с пояснением на русском и английском. Она не отправляет запросы и не собирает данные. Рабочая локальная форма и файловый API сохранены в исходниках. Контакты и Telegram-бот пока не подключены. До их настройки тестовый адрес предназначен для просмотра дизайна.

Шрифты и изображения локальные. Языки, кейсы, метаданные и навигация учитывают префикс размещения. В Pages-сборке принудительно отключена индексация. Файлы `.data`, `.env`, `.qa`, локальные архивы и зависимости не публикуются.
